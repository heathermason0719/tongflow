# 配音完整链路验收

**这是本地模拟接口验收，不是真实百炼生成验收。** 浏览器、上传、节点连接、
服务端任务、插件进程、SSE、数据库保存、工作流导出和 Python 执行器均为真实代码。
模型返回由本地服务模拟；参考声音是 macOS Tingting 合成语音，输出是测试音。
本目录只包含可以公开的合成文案、请求记录与截图，不包含用户文案、音频、凭据或数据库。

入口：[创作者使用说明](../../script-to-cloned-speech.zh.md)。复验脚本：
`scripts/verify-speech-workflow.mjs`；本地完整原始证据目录记录在 `acceptance.json`。

| 要求 | 实际证据 |
| --- | --- |
| 文案取得 | 浏览器上传 1250 字符合成 TXT，真实插件本地提取，逐字相等 |
| 智能拆分 | `acceptance.json` 的 `split` 保存原文、14 段全文、顺序与每段长度；拼回原文逐字相等，每段不超过180字符 |
| 独立音频连接、断开、复用 | `03` / `04` 截图；真实鼠标拖线、拖开端点并确认删除，再次连接；无重复上传 |
| 多段共用同一声音 | `batch` 保存14段有序音频关联和请求；每次参考音频 SHA-256 相同 |
| 并行完成顺序 | 本地接口故意打乱返回先后；结果列表和音频输出仍按原文顺序 |
| 逐段播放、下载 | `playback` 的14段时长、播放进度和错误状态；14份下载哈希与接口输出一致 |
| 上游修改与请求一致 | `editAndRerun` 保存349字符修改稿、当前预览、4段新模型请求；`06` / `07` 对照 |
| 历史输出失效 | 改稿后旧分段不再作为可执行输入；旧配音标记为历史；重跑由14段变4段 |
| 保存和重开 | 真实保存对话框、刷新、离开原画布、从工作流库打开；参数、文本、声音、连线、配音记录均保留 |
| 整条工作流重执行 | 从执行模式播放按钮及确认对话框触发；使用应用真实导出结果；Python 引擎完成，4段音频对应修改稿；见 `09` 与 `engine` |
| 手工编辑解析结果 | 解析输出被显式编辑后作为手工源；重跑解析另建输出，未覆盖编辑稿，整条链仍使用编辑稿 |

`simulated-provider-requests.json` 为本地模型接口实际收到的正文与声音哈希。
音频模型请求含 Qwen Audio 插件添加的 `@voice1` 和引号包装；正文与展示的分段一致，
仅语音提示词包装会去掉段首尾空白。分段资产与提交给插件的文本保留原始空白。

代码检查通过：155项 Vitest、91项 Python SDK 测试、19项 OpenAI 插件测试，
主应用及包的 TypeScript 检查、插件扫描、生产构建。文档与音频下载回归结果在
`regression-summary.json` 中单独记录。

尚未证明：真实百炼服务的当前账号可用性、真实模型分段质量、克隆相似度、读音和
生成时长／截尾表现。自动化未覆盖运行中的进程崩溃恢复或所有第三方 TTS 插件。
