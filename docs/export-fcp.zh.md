# 导出 Final Cut Pro 配音剪辑工程

1. 在工作台打开已有工作流，找到包含全部配音的「音频（N）」节点。
2. 打开节点右上角操作菜单，选择「导出 FCP 剪辑工程」。
3. 输入工程名称，点击「选择位置并导出」，在 Chrome 原生面板选择父文件夹。
   Chrome 询问是否允许修改该文件夹时，选择「允许」。
4. 等待完成。选中的位置下会新建工程目录：

```text
工程名称/
  工程名称.fcpxml
  Audio/
    01.wav
    02.wav
    ...
    16.wav
```

同名目录已存在时，自动使用「工程名称 (2)」等新目录，保留此前导出。
输出保持音频节点现有顺序；批量配音的音频节点沿用文案顺序，不按请求完成时间排序。
素材为逐文件原样复制，不拼接、不转码、不重新配音，也不改动工作流或历史结果。
非 WAV 素材保留实际格式的扩展名，不能把 MP3 改名成 WAV。超过 99 段时序号自动加宽。

## 在 FCP 中打开

在 Final Cut Pro 选择「文件 → 导入 → XML」，选择导出的 `.fcpxml`。
如果同时打开多个资源库，FCP 会询问导入目标；建议先「文件 → 新建 → 资源库」
建立剪辑用的新库，再将 XML 导入该库。双击导入的项目，打开时间线。
参见 [Apple 的 XML 导入说明](https://support.apple.com/zh-cn/guide/final-cut-pro/verdbd66ae/mac)。

每份音频是一个独立片段，默认首尾相接，无额外停顿，可在 FCP 自行移动、删减。
项目使用 1080p/25fps、48kHz 立体声时间线；音频素材维持各自真实采样率和声道，
各段时间使用有理数保存，不按毫秒或视频帧逐段取整。

XML 通过 `./Audio/01.wav` 等相对路径引用旁边的素材。首次导入前不要单独挪走
XML 或 Audio；保留整套目录。当前 Mac 上的 Final Cut Pro 12.3 已实测直接定位素材，
不需要重新链接。导入后 FCP 自己的拷贝／引用媒体策略由资源库设置决定；若之后
移动已被 FCP 引用的素材，可能仍需使用 FCP 的重新链接功能。

## 单段下载

在克隆配音结果中的「下载这一段」下载当前第 7 段，会得到 `07.wav`。
已能追溯到批量结果的单音频节点也采用相同序号；无法确定批次位置的独立素材
仍沿用原有名称。下载与工程复制都保持原文件字节。

## 条件与错误处理

第一版使用本机 Chrome 的目录读写能力，以及 TongFlow 本机磁盘素材。通过
`http://localhost:3000/workspace` 打开；不支持目录读写的浏览器会明确提示使用 Chrome。
云端存储、自定义宿主及远程浏览器文件系统未在本版验收，不声明可直接使用。

服务端需可运行 FFmpeg 和 ffprobe，可用 `FFMPEG_PATH` / `FFPROBE_PATH` 指定命令路径。
导出前逐份检查文件、精确时长及实际解码；某段缺失、为空或不可解码时，错误会指出
段号，并停止创建工程。原有 Qwen WAV 可能有偏大的流式文件头长度；实际 PCM 可
完整解码时允许导出，保持原头与音频字节，不偷偷修复或转码。

复制中断或写入失败会显示错误，并尝试清理本次新建的不完整目录；清理失败时明确
显示目录名。只有全部音频复制成功后才写入 FCPXML。取消位置选择不会创建工程。

真实 16 段 Chrome 导出、哈希、完整解码及 FCP 回读证据见
[验收记录](evidence/fcp-export/README.md)。没有调用任何真实付费模型。
